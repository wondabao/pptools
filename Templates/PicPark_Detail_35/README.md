## 排列公式

第 1 页是封面。第 n 页（2 ≤ n ≤ 35）使用从 0 开始的行号 `r = floor((n - 2) / 2)`，偶数页在左列，奇数页在右列。

- 左列：`x = 37.5`，`y = 1108.502742 + 536 × r`。
- 右列首行：`x = 948.5`，`y = 1108.502742`。
- 右列其他行：`x = 949`，`y = 1109.002742 + 536 × r`。
- 内页统一：`w = 885`，`h = 497.994516`，`radius = 20`。

配置文件逐项保存全部 35 个槽位，工具无需再次推算。若未来需要其他输出宽度 W，可将 x、y、w、h、圆角和间距统一乘以 `W / 1872`；工具已支持自定义输出宽度，图片、边距、间距、圆角和页码统一等比缩放；最终位图高度向上取整到整数像素。

## 工具使用行为

应用默认选中此模板。第 1 页进入封面，其余页按从左到右、从上到下填入；多于 35 页会提示，不会静默丢页。

`imageFit: "fill"` 表示等比放大并居中裁切，**不会拉伸图片**。16:9 内页对这个槽位仅需裁掉极少量左右边缘；4:3 等不同比例也按等比填满规则裁切。

默认去掉末尾没有页面的行，保留原槽位位置和约 51px 底边距。这是适配 1–35 页的工具行为，并非修改原 PSD：

- 1 页：1872 × 1113 px。
- 3 页：1872 × 1658 px。
- 35 页：1872 × 10234 px。

勾选「保留模板完整高度」即可始终输出 1872 × 10234。最后一行只有左页时，右侧保留背景，不会将左页拉大。新图只包含用户导入的页面，不带原 PSD 中的示例文稿内容。

## 自定义宽度示例：1400 px

缩放系数 `s = 1400 / 1872 = 0.7478632479`。模板坐标先乘以 s，再将每个槽位的左、上、右、下边界四舍五入到整数像素。宽高由取整后的边界相减得到，边距和间距因此也为整数；圆角、阴影距离和页码尺寸同样取整，颜色和透明度保持不变。各位置独立依据原始坐标计算，不逐行累加取整误差。

| 项目 | 1400px 宽下的尺寸 |
| --- | --- |
| 封面图片 | 1344 × 756 px |
| 封面左右边距 | 28 px |
| 双列图片 | 662 × 372 或 373 px（按边界取整） |
| 双列左边距 | 28 px |
| 双列右边距 | 首行 29 px，其他行 28 px |
| 双列列间距 | 首行 19 px，其他行 20 px |
| 同列行间距 | 28 或 29 px（按边界取整） |
| 圆角 | 15 px |
| 3 页实际输出 | 1400 × 1240 px |
| 保留完整模板高度 | 1400 × 7654 px |

在「打磨细节」输入输出宽度，或点击 1400 快捷按钮即可。分页图片的清晰度设置与详情图宽度独立。

按用户要求，最终输出全部对齐整数像素；相邻图片高度或间距可能相差 1px，这是保留整体比例与位置的取整结果。图片内容仍按原宽高比缩放后裁切，不拉伸。
